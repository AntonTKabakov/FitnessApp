# Fitness App

A fitness management system designed to help gyms manage customers, memberships, trainers, and check-ins efficiently.

## Features

- Customer management
- Gym pass management
- Purchase and tracking of customer passes
- Check-in registration
- Trainer management
- User authentication with JWT and refresh tokens

## Technologies

- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Figma (UI Design)
